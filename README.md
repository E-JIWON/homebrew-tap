# E-JIWON Homebrew Tap

```bash
brew tap e-jiwon/tap
brew install --cask clipshelf
```

| Cask | App |
| --- | --- |
| `clipshelf` | [ClipShelf](https://github.com/E-JIWON/clipshelf) — clipboard shelf on the edge of your Mac screen |

Apps are not notarized yet. If macOS blocks the first launch, use `brew install --cask --no-quarantine clipshelf` or `xattr -cr /Applications/ClipShelf.app`.
